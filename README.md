## PMA Voice - Distance Control

Easily adjust your voice chat distance in-game using `Alt + Scroll Wheel`.

Quickly switch between different voice ranges without opening any menus, giving you more control over how far your voice can be heard.

### Preview

![PMA Voice Preview](preview.gif)

### Controls

- **Alt + Scroll Up** — Increase voice distance
- **Alt + Scroll Down** — Decrease voice distance
